## 🔐 Step 1 — Get Pair Code

> ⚡ You need to link your account to generate the session files. The easiest way is using a Pair Code.

<div align="center">

<a href="https://gabriel-bot-pairing.onrender.com">
<img src="https://img.shields.io/badge/──────────────────────────────────────────-000?style=for-the-badge" /><br>
<img src="https://img.shields.io/badge/%F0%9F%94%90%20GET%20YOUR%20PAIR%20CODE-Click%20Here%20to%20Generate-33ff00?style=for-the-badge&labelColor=0d1117&logoColor=white" height="45" />
</a>

</div>

<br>

```
1. Click the button above.
2. Enter your phone number with country code (e.g., 2547...).
3. Copy the code provided.
4. Open WhatsApp -> Linked Devices -> Link with Phone Number.
5. Enter the code and wait for cred.json file to generate.
```

## ⚙️ Configuration

> Edit the `settings.js` file number and bot owner to customize your bot.

### 🔑 Basic Settings

| Variable | Default | Description |
|----------|:-------:|-------------|
| `botName` | `Gabriel MD Bot` | The name displayed by the bot |
| `ownerNumber` | `254716427334` | Your WhatsApp number (without +) |
| `prefix` | `,` | Command prefix (e.g. `.` or `,`) |
| `commandMode` | `public` | `public` or `private` |

### 🛡️ Protection Features

| Feature | Command | Description |
|---------|---------|-------------|
| **Anti-Scam** | `.antiscam` | Detects and removes fraud messages |
| **Anti-Link** | `.antilink` | Automatically deletes group links |
| **Anti-ViewOnce**| `.antivv` | Forwards view-once media to owner |
| **Anti-Delete** | `.antidelete`| Recovers deleted messages |
